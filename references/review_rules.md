# 车险报价人工核对规则

## 先核实可比性

核对车辆配置、使用性质、初次登记、出险信息、商业险与交强险起止时刻。不同报价的车损保额、三者保额、车上人员责任险、医保外医疗、附加险和免赔条件要逐项展示。保额不一致时，先请销售说明估值依据或按相同口径重报，再判断差价。

## 费用分层

应付总价 = 商业险 + 交强险 + 车船税 + 报价中已计入的单列产品。任何组成部分未列出时，先确认是 0 元、不适用，还是报价缺项；不能自行填 0 补齐。返现是销售承诺时，只展示“兑现后可能净支出”。另购服务包和服务券另列，不自动抵扣。对权益的价值要看用户实际会不会用、适用地点、有效期和使用成本；这些规则不依赖城市、品牌或门店。

## 附加的人身保障

把车上人员责任险与单列驾乘意外产品分别列出。报价表头的保险金额可能受主被保险人、乘客年龄、共享保额、免赔额和赔付比例限制；未拿到完整条款时，不凭表头数字断言每个人可获同等赔付。已有其他意外险是否重复，需看被保险人、责任场景和条款。

## 结论门槛

先给用户当前最有用的判断：若报价范围和核心保障可比，可以指出优先方案及理由；若关键差异尚未解释、返现条件不明、赠券是否可用未核，给出条件性建议。对每位相关销售，提供一段简短、可直接复制的询问文字，准确写出需要重报或确认的事项，不声称优惠已获保证；用户带回回复后重新核算并更新结论。取得重报、正式条款及用户需求后再做最终选择。电子保单应与投保前确认的版本复核。
